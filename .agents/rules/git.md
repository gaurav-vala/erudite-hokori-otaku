# Git Guidelines

## Critical Rule: Never Commit

- **NEVER run `git commit` under any circumstances.**
- Do not create commits, amend commits, or trigger automated git commits (`git commit`, `git commit -m`, `git commit -am`, etc.).
- Keep all file edits, additions, and deletions in the working tree or staging area for manual review.
- The user retains sole authority over committing and pushing changes to version control.
